Classical Oracle Search

A box hides one 3-bit value, one of the 8 values from 000 to 111. You cannot open the box. You can only ask it about one candidate at a time, and it answers 1 if the candidate is the hidden value and 0 otherwise. In code this box is a function that returns true or false. Here the same function is built from logic gates, the way quantum algorithms build their oracles. Every query adds one block to the circuit: write the candidate onto 3 input bits, ask the oracle, and copy the candidate into a result register only if the oracle said 1. There is no clock and no loop. Each query is a separate copy of the oracle in the circuit, so the number of oracle boxes is the cost of the search. Searching one candidate at a time takes up to 8 queries for 8 values. Build the search step by step until the result register reveals the hidden value, and open the oracle whenever you want to see how x == hidden becomes gates.

How to use this page
  1. Press Try next untested, or set the 3 candidate bits yourself and press Add query.
  2. Each query adds one block to the circuit: set candidate → oracle → copy if found.
  3. Keep adding queries until the oracle answers 1. The result register then shows the hidden value.
  4. Turn on Show inside the oracle to see the gates behind x == hidden.
  • The highlighted button marked ← next is a good next step.
  • Click a value in the candidates list to load it into the candidate bits.
  • ◀ Back and Forward ▶ (or the ← → keys) step through the queries. New hidden value starts a fresh search.
  • Set hidden value lets you choose the hidden value yourself, for example to set a search for someone else. The choice is not left on screen and the oracle closes.
